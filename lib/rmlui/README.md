# RmlUi

Библиотека интерфейса на HTML/CSS-подобной разметке. Взята как есть с
https://github.com/mikke89/RmlUi, выпуск 6.3 (22.08.2026), автор Michael
Ragazzon и участники. Лицензия MIT, текст в LICENSE.txt.

Зачем: на ней строятся меню движка вместо formspec — главное меню, экраны
крейтов, позже HUD. Разметка и стили лежат файлами и правятся без сборки,
логика — в C++ в `src/ui/` и `src/client/menu/`.

Из выпуска взяты только `Include/`, `Source/Core/` и `Source/Debugger/`.
Плагины Lua, SVG и Lottie, бэкенды, примеры и тесты не нужны: рендер и ввод
у движка свои, поверх Irrlicht, и лежат в `src/ui/`. Сборочные файлы
библиотеки заменены своим CMakeLists.txt — родные тянут установку, пакеты
и выбор бэкенда, а здесь нужна одна статическая библиотека со шрифтами
через FreeType, который у движка уже есть.

Файлы не правились и не должны: при обновлении их заменяют целиком.
